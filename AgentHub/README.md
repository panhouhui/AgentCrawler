# AgentCrawler / AgentHub

AgentCrawler 是一个面向多平台社交信息发现、分析和聚合的智能体系统。前端应用名称为 AgentHub，主要用于把多个平台的爬虫能力接入智能体，让系统可以自主发现事件、判断事件价值、跨平台复核证据，并输出统一的社交融合分析结果。

## 项目有什么用

这个项目适合用来做多平台社交情报监控和事件分析。它不是简单的关键词爬取，而是让不同平台的智能体各自巡逻、发现事件、提取证据，再由社交融合智能体进行统一判断。

核心目标：

- 让各个平台智能体自主发现最新热点或异常事件。
- 对候选事件做中国相关性和风险门槛判断。
- 让其他平台智能体复核同一事件是否也在传播。
- 汇总 URL、频道、帖子、内容、评论和传播指标等证据。
- 判断多个平台看到的是不是同一个事件。
- 输出事件影响等级、传播路径、核心传播节点和趋势。
- 对重复事件做过滤，减少同一事件反复推送。
- 通过前端页面查看智能体运行状态、证据、融合结果和推送队列。

## 主要功能

### 社交融合监控

平台智能体会先从各自平台发现候选事件，然后交给中国相关性与风险判断模块筛选。通过筛选后，社交总控 Agent 会通知其他平台智能体复核同一事件。所有平台返回结构化证据后，Social Fusion Agent 会进行跨平台融合。

融合结果会包含：

- 事件标题
- 影响等级
- 同一事件置信度
- 传播路径
- 核心传播节点
- 平台证据
- 未发现平台
- 趋势判断
- 建议动作

### 平台智能体

当前社交平台智能体包括：

- X
- Telegram
- LIHKG
- Facebook
- GitHub
- Instagram
- Lien
- NetLight
- PTT
- YouTube

每个平台智能体可以接入自己的爬虫工具，返回对应平台的公开 URL、频道、帖子、评论、内容摘要和传播指标。

### 爬虫配置中心

前端提供爬虫配置页面，用来查看各个平台配置是否就绪。不同平台可以有不同的认证方式、代理或脚本入口。

### Kan 推送配置

项目提供统一的 Kan 推送配置页面，用来管理不同爬虫平台和社交融合结果的推送路由。社交融合结果达到阈值后，可以进入统一推送队列。

### 模型配置

智能体分析能力通过模型配置接入。当前社交智能体默认面向 MiniMax 兼容 Anthropic 接口设计，也可以扩展其他模型路由。

### 前端控制台

AgentHub 前端包含：

- 总览
- 爬虫配置
- Kan 推送配置
- 社交融合监控
- 智能体管理
- 工具管理
- 会话
- 路由
- 系统状态

## 运行流程

```text
平台智能体自主发现事件
  -> 候选事件池
  -> 中国相关性和风险判断
      -> 不相关或风险不足：跳过 / 低优先级观察
      -> 通过：社交总控 Agent
          -> 通知其他平台复核同一事件
          -> 平台爬虫工具返回 URL / 频道 / 内容 / 指标
          -> 平台证据报告
          -> Social Fusion Agent
          -> 事件融合、传播路径、关系链
          -> 阈值判断和重复过滤
              -> 通过且非重复：进入推送队列
              -> 重复或不足：持续监控
```

## 项目目录

```text
AgentCrawler/
  README.md
  package.json
  src/
    agent/                  # 智能体运行与模型调用
    agents/                 # 智能体注册与定义
    cli.ts                  # 命令行入口
    config/                 # 配置加载、模型环境读取、项目根目录识别
    integrations/
      crawlers/             # 爬虫配置读取与平台配置汇总
      kan/                  # Kan 推送配置、路由和投递客户端
    pipelines/
      social/               # 社交智能体流程、门槛判断、融合、去重、渲染
      ideas/                # 原有情报/想法分析能力
    store/                  # 数据库访问、迁移和社交监控状态
    tools/                  # 智能体工具，包括爬虫工具封装
    web/                    # Hono API、前端资源和路由
      routes/               # Web API 路由
      ui/                   # React 前端页面
  scripts/                  # 验证、预览和辅助脚本
  docs/                     # 设计说明和扩展文档
```

## 外部目录

实际部署时，爬虫脚本和环境配置通常放在项目外部，和应用代码分开维护：

```text
AgentHubRoot/
  AgentCrawler/             # 本项目
  Crawler/                  # 外部爬虫脚本
  env/
    model_env/              # 模型配置
    Crawler_env/            # 各平台爬虫配置
  test/                     # 工具运行输出
```

项目可以通过环境变量指定这些目录：

- `AGENT_HUB_ROOT`
- `CRAWLER_ROOT`
- `MODEL_ENV_ROOT`
- `CRAWLER_ENV_ROOT`

## 基础启动

安装依赖：

```bash
bun install
```

类型检查：

```bash
bun run typecheck
```

启动核心服务：

```bash
bun run start
```

启动前端服务：

```bash
bun run start:web
```

默认前端地址：

```text
http://127.0.0.1:48086
```

## 项目定位

AgentCrawler / AgentHub 的重点是把“平台爬虫”升级成“平台智能体”，再通过社交融合智能体统一判断跨平台事件。它更适合作为多平台事件监控、证据归集、关系链分析和推送决策系统的基础框架。

本项目基于 OpenCrow 代码底座改造，当前应用和前端体验面向 AgentHub / AgentCrawler 场景维护。
